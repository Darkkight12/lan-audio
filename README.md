# LAN Audio

LAN Audio is a web-based audio streaming app that allows you to stream audio from one device and listen to it on another device connected to the same local network.

It is useful for playing audio from a PC/laptop and listening to it on a phone or another device through a browser.

## Features

- Stream audio over a local network
- Works through a web browser
- No app installation required on the receiving device
- Supports access from mobile phones, tablets, and laptops
- Simple LAN-based setup
- Built using Next.js

## Tech Stack

- Next.js
- React
- TypeScript
- Node.js
- Tailwind CSS

## Requirements

Before running the project, make sure you have:

- Node.js installed
- npm installed
- Devices connected to the same Wi-Fi/LAN network
