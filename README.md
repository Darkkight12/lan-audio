## 🎬 Perfect for Movie Nights with Friends

Want to watch a movie together without disturbing others? **LAN Audio** is designed for local-network audio sharing, making it a useful project for group movie nights, shared listening, and personal audio setups.

### 🎧 Multiple Headphones, One Movie

- 📱 **Use Phones as Audio Devices** — Use compatible phones as part of your audio setup.
- 👥 **Watch Together** — Let friends listen to the same movie while watching on a shared screen.
- 🎧 **Multiple Headphones** — Build a shared listening setup without requiring a separate Bluetooth connection for every listener.
- 🌐 **Local Network Streaming** — Use your existing Wi-Fi network to connect compatible devices.
- 🤫 **Private Listening** — Enjoy movies together using headphones instead of speakers.

### 🍿 Use Cases

- Movie nights with friends
- Watching films in a hostel or shared room
- Watching videos together without disturbing others
- Group listening sessions
- Sharing computer audio with phones over a local network

> **How it works:** The computer plays the movie, and audio is streamed over the local network to compatible receiver devices. Each listener connects their headphones to their own phone.

**Note:** Multiple-device playback depends on the receiver implementation and network setup. Synchronization and latency may vary between phones, so test lip-sync performance before relying on it for movies.
